# ApexSales - Executive Sales Analytics Dashboard

A responsive single-page sales analytics dashboard built with vanilla HTML, CSS, and JavaScript.

## Features
- **Zero Dependencies & Pure Vanilla Stack**: Pure HTML5, CSS3, and ES6+ JavaScript without external libraries or frameworks.
- **No CSS Variables**: Explicit styling architecture adhering to strict environment constraints.
- **Persistent WebStorage**: Utilizes browser `localStorage` to manage records persistently with realistic pre-populated seed data.
- **Interactive Visualizations**:
  - Revenue & Deal Volume timeline curve chart with hover inspection.
  - Sales by Solution Category donut chart with dynamic proportional breakdown.
  - Regional Market Performance horizontal bar chart with target lines and quota pacing.
- **Sales Rep Leaderboard**: Ranks representatives by closed deals, volume, and quota contribution.
- **Full Transaction Ledger**: Search, filter by category & payment status, multi-column sorting, and pagination.
- **Data Management**: Modal for adding or editing sales transactions, row deletion, CSV export, and demo data reset.

## Getting Started
Simply open `index.html` in any modern web browser. No server, build step, or authentication required.
